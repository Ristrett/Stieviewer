SiteSee Mobile Viewer

หน้านี้ไม่มีระบบ login ของ SiteSee จึงเปิดจาก URL ของ app.sitesee.com.au ตรงๆ ไม่ได้ — ต้องใช้ ลิงก์ข้อมูล (มี token อายุ ~4 ชม.) ที่ bookmarklet สร้างให้จากหน้า job ที่ login แล้ว

  1. เปิด app.sitesee.com.au/site-viewer/<job> ใน Chrome (login Microsoft ตามปกติ) รอโมเดลขึ้น
  2. กด bookmark Ein viewer (บนมือถือ: พิมพ์ชื่อ bookmark ในช่องที่อยู่แล้วแตะ) → หน้านี้จะเปิดพร้อมงานนั้น
  3. หรือวางลิงก์ที่ bookmarklet ให้ (ขึ้นต้นด้วย …viewer.html#job=) ในช่องด้านล่าง
ยังไม่มี bookmark "Ein viewer"? ติดตั้งที่นี่

สร้าง bookmark ใหม่ ตั้งชื่อ Ein viewer แล้ววางข้อความด้านล่างทั้งหมดเป็น URL ของ bookmark (ครั้งแรกที่กดจะถาม URL ของหน้านี้ ซึ่งคือ )
